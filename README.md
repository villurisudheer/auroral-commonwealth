# AURORAL COMMONWEALTH

### Build. Govern. Trade. Survive.

**AURORAL COMMONWEALTH** is a browser-based geopolitical strategy and economic simulation game where every major decision affects the country you control.

Build industries. Manage taxation. Expand infrastructure. Secure energy. Research technology. Trade strategic resources. Navigate diplomacy. Survive national crises. Compete for global influence.

The game supports **single-player, LAN multiplayer, and online multiplayer for up to 20 human players**.

---

## About the Game

Can you build a powerful nation without destroying its economy in the process?

In AURORAL COMMONWEALTH, your country is more than a flag and a GDP number. You are responsible for the systems that keep a nation functioning:

**Treasury · Taxation · Government Spending · Debt · Inflation · Employment · Industry · Energy · Infrastructure · Education · Healthcare · Technology · Resources · Trade · Diplomacy · Public Approval · Political Stability**

Every major choice involves trade-offs.

Raise taxes and government revenue may improve, but business activity and public approval can suffer.

Invest heavily in infrastructure and industry and the economy may grow, but construction costs, maintenance, debt, energy demand, and resource consumption all increase.

Ignore energy security and industrial productivity can fall.

Depend too heavily on imports and a global shortage can quickly become a domestic crisis.

There is no permanently perfect strategy.

## National Crisis System

Poor decisions do not always end the game instantly.

A country can move through escalating stages:

**Warning → Crisis → Emergency → Collapse**

Potential causes include:

- Excessive debt
- Persistent budget deficits
- Severe inflation
- Energy shortages
- Food shortages
- Economic depression
- Political instability
- Extremely low public approval

Recover early enough and the nation may stabilize.

Wait too long and major systems can begin to fail.

## LAN Multiplayer

1. Start the game server on the host computer.
2. Connect all players to the same Wi-Fi/router.
3. The terminal will display a LAN address similar to:

```text
http://192.168.1.20:8000
```

4. Other players open that address in their browsers.
5. The host selects **Multiplayer → Create Room**.
6. Other players select **Join Room** and enter the room code.
7. Every player chooses a different country.
8. The host starts the shared simulation.

If another device cannot connect, allow Node.js through the host computer's private-network firewall.

## Internet Multiplayer

The same multiplayer server can be deployed publicly.

The game uses WebSockets for live multiplayer synchronization and automatically uses secure WebSockets (`wss://`) when hosted over HTTPS.

A `Dockerfile` is included for container deployment.

### Docker

Build:

```bash
docker build -t auroral-commonwealth .
```

Run:

```bash
docker run -p 8000:8000 auroral-commonwealth
```

## Render Deployment

AURORAL COMMONWEALTH can be hosted as a Render Web Service.

Recommended configuration:

```text
Runtime: Docker
Dockerfile Path: ./Dockerfile
Docker Build Context Directory: .
Docker Command: leave blank
```

The multiplayer server automatically reads the hosting provider's `PORT` environment variable.

After deployment, players only need the public game URL and multiplayer room code to join.

## Design Philosophy

AURORAL COMMONWEALTH follows one central rule:

> **Major decisions should have both benefits and costs.**

The simulation is designed to avoid obvious unlimited-resource exploits.

There is no intended:

- Infinite treasury
- Unlimited resources
- Free infrastructure
- Instant research
- Infinite borrowing
- Permanently increasing GDP
- Single policy that is always optimal

Economic growth depends on interacting systems including taxation, spending, industry, technology, infrastructure, trade, energy, employment, debt, resources, and national stability.

The objective is to create strategic decisions where the player must balance short-term benefits against long-term consequences.
